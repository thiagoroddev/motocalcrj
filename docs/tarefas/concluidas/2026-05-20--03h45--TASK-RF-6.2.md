## Planejamento Aprovado

Implementar `src/pages/PaginaVidaUtil.tsx` com duas seções:

**1. Combustível**
- Cards para `comum` e `aditivada` sempre visíveis; `etanol` somente se `CATALOGO[modelo].aceitaEtanol === true`
- Cada card: preço (R$/L) editável, autonomia (km/L) editável, badge "Preferido" + botão "Usar este" via `SET_TIPO_COMBUSTIVEL_PREFERIDO`
- Reset por tipo: restaura `perfilPadrao` preço + autonomia derivada do catálogo (via `SET_COMBUSTIVEL` × 2)
- `IconeReset` visível quando preço ou autonomia diferem do padrão

**2. Peças e Pneus**
- Lista `preset.pecas[]` (inclui `oleo_motor`) + `preset.pneus[]`
- Cada item: nome, preço editável via `SET_PECA_OVERRIDE campo:'preco'`, vida útil somente leitura
- Vida útil: `servicosIndependentes.find(s => s.id === item.id)?.intervalKm` ?? fallback do preset
- Preço exibido: `override.precoEditado ?? (perfilPecasGlobal === 'original' ? precoOriginal : precoParalela)`
- Hint com ambos os preços do preset (Original / Paralela) como referência
- `IconeReset` visível quando `override.precoEditado !== null`; reset via `RESET_PECA_OVERRIDE campo:'preco'`

Ajustes adicionais confirmados durante aprovação:
- Óleo do motor deve aparecer na seção Peças (já é `preset.pecas[0]`, comportamento natural)
- Etanol oculto quando `!CATALOGO[modelo].aceitaEtanol` (Pop 110i: `aceitaEtanol: false`)

## Execução

- Padrão `IconeReset` / `useEffect` / `onBlur` idêntico ao `PaginaMaoDeObra.tsx`

## Decisões Tomadas

- **Vida útil sempre read-only nesta aba**: o `intervalKm` que governa o cálculo pertence ao serviço (Mão de Obra). Alterar aqui criaria ambiguidade com ADR-004. Exibido como `<div>` estilizado como input desabilitado.
- **Hint Original/Paralela como referência**: linha com ambos os preços do preset abaixo do input ajuda o usuário a saber o que está editando sem precisar navegar a outra tela.
- **Reset combustível sem nova action**: `SET_COMBUSTIVEL` disparado duas vezes (preco + autonomia) é suficiente; evita ampliar o reducer por caso único.
- **`aceitaEtanol ?? true`**: fallback para `true` garante que modelos futuros sem catálogo exibam etanol por padrão (comportamento conservador).

## O Que NÃO Foi Feito (e Por Quê)

- **Toggle global Original/Paralela**: pertence ao TASK-RF-6.3 (Tela Perfil). Esta aba apenas consome `perfilPecasGlobal` existente.
- **Toggle por item Original/Paralela**: `PecaOverride.perfilPecasOverride` existe no tipo mas o MVP usa apenas `precoEditado`. Funcionalidade reservada para refinamento futuro.
- **Mapping explícito serviço↔peça**: DT-15 documenta o risco; mapeamento explícito seria escopo de tarefa futura quando houver múltiplos modelos.

## Aprendizados Para o Projeto

- O campo `aceitaEtanol` no `DadosModeloCatalogo` é a fonte canônica para condicionar UI de combustível — manter consistente ao adicionar novos modelos.
