## Planejamento Aprovado

Instalar a Inter como pacote, importar apenas o subset necessário, remover as 3 tags do
`index.html` e garantir que o `woff2` entre no precache do Workbox.

**Motivo:** a fonte por CDN contradizia **três afirmações públicas do projeto**:

1. **"Offline-first"** — README e ADR de arquitetura afirmam "nenhuma API em runtime" e "funciona
   offline em 4G ruim". A fonte era requisição externa bloqueante de render no 1º acesso, no
   cenário exato do público-alvo (motoboys em conexão móvel).
2. **"Local-first por privacidade"** — o README justifica a ausência de backend por privacidade,
   mas toda visita entregava IP e User-Agent ao Google antes da primeira tela pintar. Google Fonts
   por CDN já foi julgado violação de GDPR na Alemanha (LG München, 2022); o argumento vale para a
   LGPD.
3. **Bloqueava a CSP restritiva** da `TASK-RNF-015` — mantê-la exigiria abrir `style-src`/`font-src`
   para domínios do Google.

**Critérios de aceite:** nenhuma requisição a domínio externo no carregamento; tipografia
visualmente idêntica; `npm run verify` verde; fonte disponível offline após o 1º acesso.

## Decisões Tomadas

- **Fonte variável em vez de 4 arquivos estáticos.** A UI usa 4 pesos; o arquivo variável cobre
  100-900 num download só. Para PWA com precache, menos entradas e menos bytes totais.
- **Subset `latin` apenas, com `@font-face` declarado à mão.** Importar o CSS pronto do pacote era
  mais idiomático, mas custava ~166 kB de precache em alfabetos que o app não renderiza. A
  declaração manual é ~15 linhas e mantém o precache honesto. O `unicode-range` foi copiado do
  próprio Fontsource para não inventar cobertura.
- **`Inter` mantida como fallback** depois de `'Inter Variable'`: quem já tem a Inter instalada no
  sistema usa a local; ninguém fica sem a fonte se o woff2 falhar.
- **`vite.config.ts` não foi tocado.** O `globPatterns` já contemplava `woff2` — mudar o que já
  funcionava seria alteração sem efeito.

## O Que NÃO Foi Feito (e Por Quê)

- **Subset `latin-ext` (83,1 kB):** não é necessário para português. Se o app um dia exibir nomes
  com caracteres do leste europeu ou turco, é adicionar um segundo `@font-face` — o `font-display:
  swap` e o `unicode-range` fazem o navegador buscar só o que precisa.
- **Itálico:** a UI não usa. O pacote traz `inter-latin-wght-italic.woff2` (51,8 kB) que ficou de
  fora deliberadamente.
- **`preload` da fonte no `<head>`:** melhoraria o LCP do 1º acesso, mas é otimização de
  performance que pertence à `TASK-RNF-9.1`, com medição do Lighthouse para provar o ganho.
- **Aviso de chunk > 500 kB:** preexistente, rastreado na `TASK-REF-47`.

## Aprendizados Para o Projeto

- **"Offline-first" e "sem backend" não sobrevivem a um `<link>` para CDN.** A afirmação estava
  escrita no README e era falsa desde o primeiro deploy — não por descuido de escrita, mas porque
  ninguém tinha um comando que conferisse origens externas no build. `grep -rl "googleapis" dist/`
  custa um segundo e prova a afirmação.
- **O caminho idiomático nem sempre é o correto.** Importar o CSS pronto do Fontsource é o que a
  documentação recomenda e teria passado em qualquer revisão — a diferença de 166 kB só aparece
  para quem mede antes.
- **Pacotes variáveis do Fontsource registram outro nome de família** (`'Inter Variable'`, não
  `Inter`). Trocar o pacote sem atualizar o token `--font-sans` faria o app cair silenciosamente no
  `system-ui`: sem erro, sem teste quebrado, só a tipografia errada — exatamente a classe de
  regressão que só a validação visual pega.
