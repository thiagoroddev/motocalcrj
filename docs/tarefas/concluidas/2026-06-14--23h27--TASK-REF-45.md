## Aprendizados Para o Projeto

- Campos persistidos podem permanecer como compatibilidade sem manter a feature ativa; isso evita migration quando o dado legado é inofensivo.
- Abas condicionadas ao conteúdo canônico do preset são mais extensíveis do que condições por marca.
- Ao remover uma feature, a varredura precisa abranger dados, reducer, cálculo, UI, ajuda, testes e documentação ativa; manter só o schema legado deixa o limite explícito.
