## Decisões Tomadas

- **Node 22 LTS no CI** (não o v25 local): o local é não-LTS; 22 é LTS ativo e suporta o stack (React 19, Vite 7, vitest 3). Como não há pin no repo, o CI fixa a versão de referência.
- **`npm ci` (não `npm install`):** instala exatamente o lockfile, mais rápido e determinístico. O `.npmrc include=dev` garante devDeps.
- **`on: [push, pull_request]`:** feedback tanto em push de branch quanto em PR. Trade-off aceito: PR de branch do próprio repo pode disparar 2 runs (push + pull_request) - `concurrency` por ref mitiga parcialmente.
- **Inclui `npm run build`:** além dos 3 gates, o build pega erros que só aparecem no bundle (ex.: import quebrado em produção).
