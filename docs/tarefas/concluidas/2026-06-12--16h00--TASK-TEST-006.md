# TASK-TEST-006 — Remover `any` dos testes de onboarding

- **Modo:** Standard
- **Origem:** débito de lint herdado do branch `concessionaria`, identificado na TASK-RF-6.35
- **Conclusão:** 12/06/26 16h00

## Objetivo

Zerar os 16 `@typescript-eslint/no-explicit-any` em `PassoModelo.test.tsx` (9) e
`PassoMaoDeObra.test.tsx` (7), fechando o `npm run lint` do projeto sem `eslint-disable` e preservando
o comportamento asseverado.

## O que mudou

- `src/pages/onboarding/passos/PassoModelo.test.tsx`:
  - Props do mock de `PassoLayout` tipadas com `PassoLayoutMockProps` (tipo local) em vez de `any`.
  - Modelos de catálogo via factory `criarModeloCatalogo` (retorna `DadosModeloCatalogo` real) —
    elimina os 8 `{ id, nome } as any`.
- `src/pages/onboarding/passos/PassoMaoDeObra.test.tsx`:
  - Props dos mocks `PassoLayout`, `ControleEstimativaMaoDeObra` e `CardServico` tipadas com tipos
    locais (`ReactNode`, `Dispatch<PerfilAction>`, `ServicoIndependente`).
  - Serviços via factory `criarServico` (retorna `ServicoIndependente` real); os campos antigos
    `autorizada`/`generico` — que não existem mais no tipo — foram removidos das fixtures.
  - `obterPreset` mockado passa a retornar `undefined` (as utils reais aceitam preset opcional),
    eliminando o `presetMock as any`.
  - Retornos de `normalizarPerfilMvp` agora são `PerfilUsuario` válidos, sem cast.

## Decisões

- **Tipos locais de props em vez de `ComponentProps<typeof X>`:** mais robusto num arquivo que mocka o
  próprio componente (evita atrito com `verbatimModuleSyntax` ao usar `typeof` sobre import mockado).
- **Único `as unknown as PerfilAction`** mantido de propósito: o mock de `ControleEstimativaMaoDeObra`
  fabrica a ação `TOGGLE_ESTIMATIVA` (que não existe no union real) só para verificar a fiação
  `onClick → dispatch`; o teste assevera exatamente esse objeto.
