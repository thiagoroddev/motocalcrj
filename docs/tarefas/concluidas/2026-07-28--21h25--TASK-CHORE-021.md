## Decisões Tomadas

- **Auditoria informativa por ora.** Ver "Planejamento Aprovado". A alternativa — excluir o advisory
  com uma allowlist sem data — é literalmente um dos anti-padrões catalogados na análise (§7.2).
  Melhor uma etapa honestamente informativa do que um gate que mente por omissão.
- **`push` em todas as branches, sem `pull_request`.** Projeto solo que trabalha com branches de
  preview e merge local; `pull_request` só duplicaria runs no mesmo commit.
- **Node 22 no CI, contra v25.9.0 local.** Divergência proposital: se o projeto só funciona na versão
  exata da máquina do autor, isso é um defeito, e o CI deve revelá-lo.
- **Husky/`pre-push` deixado de fora.** A tarefa o marcava como opcional. Ele muda o fluxo de push do
  humano (passa a rodar ~40 s de `verify` a cada push) — isso é decisão dele, não efeito colateral de
  instalar CI. Dois comandos, adicionável a qualquer momento.
- **Validado em branch descartável antes de tocar `motocustorj`.** O passo 2 deixa o CI vermelho de
  propósito; fazer isso na branch de produção sujaria o histórico de status do projeto.

## O Que NÃO Foi Feito (e Por Quê)

- **`audit:prod` bloqueante, `lint:docs`, `gate:lancamento`, orçamento de bundle:** `TASK-CHORE-023`
  e `TASK-CHORE-024`.
- **Cache de build ou matriz de versões do Node:** o run leva ~2 min; otimizar agora seria
  complexidade sem problema medido.
- **Branch protection / required status checks no GitHub:** exigiria mexer em configuração do
  repositório na web, fora do que a tarefa pedia. Vale considerar depois — é o que transforma o CI
  de *informação* em *impedimento* real de merge.

## Aprendizados Para o Projeto

- **A partir daqui, concluir tarefa Standard/Strict pede o link do run**, não a frase "gate verde".
  A diferença é que o link é falsificável por qualquer pessoa — inclusive por outro agente, meses
  depois, sem acesso a esta conversa.
- **Um badge estático é uma afirmação, não uma medição.** O README dizia "466 testes passando" desde
  antes de existir qualquer verificação externa. Estava certo, por acaso — e ninguém teria como
  saber.
- **Gate que nunca reprovou é hipótese.** Custou dois pushes e três minutos provar que este reprova.
  Todo gate novo deveria pagar esse preço uma vez.
- **CI verde no dia 1 é requisito de projeto, não vaidade.** Foi por isso que a auditoria entrou
  informativa: um CI que nasce vermelho por um problema conhecido e já analisado treina todo mundo a
  ignorar o sinal — e aí o próximo problema, real, também passa despercebido.
