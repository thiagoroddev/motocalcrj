## Aprendizados para o Projeto

- `resolve.alias '@': '/src'` (string com barra inicial) permanece funcional no Vite 6 em Windows. Não é necessário migrar para `fileURLToPath(new URL('./src', import.meta.url))` por enquanto.
- `/// <reference types="vitest" />` e `test: { environment: 'node' }` inline no `vite.config.ts` permanecem suportados no Vitest 3.
- npm resolve `^5.8.0` para `5.9.3` — ranges permissivos podem instalar versões mais novas que o alvo mínimo.
