## Decisões Tomadas

- **`omit=` com valor vazio:** valor tecnicamente inválido para o npm (que emite `warn invalid config`). O npm, ao encontrar um valor inválido, usa o default da config, que para `omit` fora de NODE_ENV=production é vazio (nada omitido). Isso sobrescreve o global `omit=dev` e é o comportamento desejado. A alternativa seria alterar o config global da máquina, o que afetaria outros projetos. Decisão: manter `omit=` no projeto com comentário documentando o comportamento.

## Aprendizados para o Projeto

- O `omit=` com valor vazio no `.npmrc` é inválido mas efetivo: o npm emite warning e usa o default (sem omit), sobrescrevendo o `omit=dev` global. Comportamento dependente de implementação do npm — pode mudar em versões futuras do npm.
- Alternativa robusta se o comportamento quebrar: remover linha `omit=` do `.npmrc` e usar `npm install --include=dev` explicitamente, ou alterar o config global da máquina.
