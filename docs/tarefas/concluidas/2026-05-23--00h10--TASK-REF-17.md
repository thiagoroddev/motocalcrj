## Aprendizados Para o Projeto
- O padrão de reset é agora `BotaoReset` (icon button com confirmação embutida) + `DialogConfirmacao` (controlled). Qualquer card editável novo deve usar `BotaoReset`; qualquer ação destrutiva deve usar `DialogConfirmacao`.
- "Reset volta ao padrão" tem semântica dupla no app: para overrides de preset (M. Obra / Custos & Peças) = volta ao valor do preset; para campos de Ajustes = zero para custo (ADR-005) ou `perfilPadrao` para uso. Não há uma regra única - depende da natureza do campo.
