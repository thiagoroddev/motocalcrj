## Decisões Tomadas

- **`@eslint/js@9` instalado explicitamente:** ESLint 9 bundleia `@eslint/js@9` internamente, mas sem instalação explícita o npm resolve `@eslint/js@*` para v10 (que requer ESLint 10), causando conflito de peer dependency. Fixado com `@eslint/js@9`.
- **`reactHooks.configs['recommended-latest']` em vez de `configs.recommended`:** `recommended` em v5.2.0 tem `plugins: { '0': ... }` (formato inválido); `recommended-latest` tem `plugins: { 'react-hooks': ... }` (flat config correto).
- **`tsPlugin.configs['flat/recommended']` espalhado no array:** é um array de 3 objetos config que setup o parser TypeScript (todos os arquivos), as regras recomendadas (scoped a `*.ts, *.tsx`) e regras adicionais. Compatível com ESLint v9 flat config.
- **Manter todos os plugins sem upgrade de versão:** `@typescript-eslint/eslint-plugin@^8`, `eslint-plugin-import@^2.31`, `eslint-plugin-react-hooks@^5`, `eslint-plugin-unused-imports@^4`, `eslint-plugin-prettier@^5` já suportam ESLint v9 e flat config em suas versões instaladas. `eslint-plugin-unused-imports` tem peer dep em `@typescript-eslint/eslint-plugin`, mantido.
- **`.eslintignore` deletado:** conteúdo (`dist`, `build`, `node_modules`) já coberto pela propriedade `ignores` no `eslint.config.js`. ESLint v9 não suporta `.eslintignore`.

## O que NÃO foi feito e por quê

- **Upgrade dos plugins ESLint:** sem necessidade versões instaladas já suportam v9/flat config.

## Aprendizados para o Projeto

- `@eslint/js` deve ser instalado com versão major idêntica ao ESLint (`@eslint/js@9` com `eslint@9`). Sem fixar a versão, o npm resolve para o latest (v10) que requer ESLint 10.
- Em `eslint-plugin-react-hooks` v5, usar `configs['recommended-latest']` para flat config. `configs.recommended` tem formato interno incorreto para flat config nessa versão.
- `tsPlugin.configs['flat/recommended']` é um array espalhar com `...` no array do flat config.
- `.eslintignore` não é suportado no ESLint v9. Migrar todo conteúdo para a propriedade `ignores` no `eslint.config.js`.
- O flag `--ext` do ESLint v8 não existe no v9. A seleção de arquivos é controlada pela propriedade `files` dentro do flat config.
