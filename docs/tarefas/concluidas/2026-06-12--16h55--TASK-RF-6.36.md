# TASK-RF-6.36 — Reformular "Apagar Tudo" em "Resetar predefinição"

- **Modo:** Standard (+ addendum à ADR-021)
- **REQ/ADR:** RF-PERF-02, ADR-021
- **Dependências:** TASK-RF-6.35 (concluída)
- **Conclusão:** 12/06/26 16h55

## Objetivo

Substituir "Apagar Tudo" (wipe global) por **"Resetar predefinição"**: reseta apenas a predefinição
**ativa** aos dados padrão (mantendo `presetId`/`sufixo`/modelo) e obriga a refazer o onboarding dela,
com aviso. As outras predefinições não são afetadas. `RESETAR_PERFIL` foi removido.

## Estratégia

Reaproveita o rascunho do "Criar nova predefinição": o reset é "um rascunho que, no commit,
**sobrescreve** a entrada existente" em vez de criar UUID novo.

## O que mudou

- `src/types/perfil.ts`: `RascunhoPredefinicao` ganhou `presetIdEmReset?: string`; nova action
  `RESETAR_PREDEFINICAO_ATIVA`; **removido** `RESETAR_PERFIL`.
- `src/context/perfilReducer.ts`:
  - `RESETAR_PREDEFINICAO_ATIVA`: abre rascunho de reset (zera o perfil para `perfilPadrao` mantendo o
    modelo da entrada ativa); rejeita sem preset ativo ou com rascunho aberto.
  - `COMMIT_ONBOARDING`: quando há `presetIdEmReset`, sobrescreve a entrada (preserva
    `presetId`/`sufixo`/`nome`/`criadoEm`) sem re-checar unicidade de sufixo; sem branch de reset segue
    criando UUID novo.
  - Removido o case `RESETAR_PERFIL`.
- `src/pages/PaginaPerfil.tsx`: botão "Apagar Tudo" → "Resetar predefinição"; diálogo de confirmação
  com aviso; `dispatch(RESETAR_PREDEFINICAO_ATIVA)` + `navigate('/onboarding/ano')`.
- `src/pages/onboarding/FluxoOnboarding.tsx`: no reset, bloqueia o passo de **modelo** (redireciona p/
  `ano`) e remove o "Voltar" no Ano — o modelo é fixo (identidade modelo↔sufixo). *(fix do bug reportado
  em validação: era possível voltar e trocar o modelo, quebrando o sufixo.)*
- `src/pages/onboarding/PassoLayout.tsx`: rótulo de cancelamento "Cancelar reset" vs "Cancelar criação".
- Testes: 5 do reducer (`RESETAR_PREDEFINICAO_ATIVA`, COMMIT sobrescrevendo, CANCELAR restaurando,
  rejeições); removido o de `RESETAR_PERFIL`. Smoke real do reset (mesmo `presetId`, sem duplicata,
  modelo bloqueado).
- Docs: glossário, `entidade-preset`, `aggregate-preset`, `aggregate-perfil`, `perfil-usuario`,
  `estado_inicial` + **addendum à ADR-021**. Esclarecimento de escopo na **ADR-019** (catálogo) com
  cross-ref recíproco à ADR-021.

## Decisões

- **Modelo preservado, onboarding começa em `/onboarding/ano`** — preserva o sistema de sufixos
  (ADR-021); trocar de modelo é caminho de "Criar nova predefinição". Passo de modelo bloqueado no
  reset (rota + botão "Voltar").
- **Reset total fora do reducer:** `RESETAR_PERFIL` removido; o wipe completo dos dados locais segue
  apenas no escape hatch do ErrorBoundary (`storage.limpar`).

## Critérios de aceite — atendidos

- [x] "Resetar predefinição" zera só a ativa e reinicia o onboarding dela; as demais ficam intactas.
- [x] Concluir sobrescreve a predefinição ativa (mesmo `presetId`/`sufixo`), sem duplicata.
- [x] Cancelar/abandonar o reset restaura os dados anteriores.
- [x] Não é possível trocar o modelo durante o reset (rota e UI bloqueadas).
- [x] `RESETAR_PERFIL` removido; reset do ErrorBoundary preservado.
- [x] Storage reflete o preset sobrescrito.
