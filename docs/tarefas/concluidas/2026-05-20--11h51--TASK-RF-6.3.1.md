## Decisões Tomadas

- **`/ajustes` fora de LayoutApp:** A tela Ajustes tem header próprio com botão `←` (Voltar), sem o header de moto. Consistente com PaginaPerfil. Navegação vinda do NavBar direto ou do botão "Editar predefinição" em PaginaPerfil.
- **`Segmentado` e `Stepper` locais:** Componentes de UI utilitários definidos no arquivo, não exportados — escopo restrito a esta página por enquanto. Candidatos a `components/ui/` se houver reutilização futura.
- **`SET_SITUACAO_MOTO` limpa campos condicionais:** Ao trocar de `financiada` para outra situação, `parcelaMensal` e `parcelasRestantes` são zerados no mesmo dispatch. Mesmo para `alugada`. Mantém invariante: campos condicionais não ficam "fantasma" no estado.
- **`RESETAR_AJUSTES_PADRAO` atualiza `categoriasAtivas`:** Ao resetar, `internet`, `seguro` e `financiamento` voltam a `false` (coerente com os valores resetados). `alimentacao` permanece inalterada pois o reset de `alimentacaoDia` para 20 implica que ela continua ativa.
- **Switch de Alimentação usa `TOGGLE_CATEGORIA`:** A flag de exibição (`categoriasAtivas.alimentacao`) é o controle do switch. O valor (`alimentacaoDia`) é preservado ao desligar, restaurado ao religar sem ação adicional.

## Aprendizados Para o Projeto

- O padrão `raw === '' ? null : isNaN(v) ? null : v` é o idioma correto para inputs numéricos com valor nullable em TypeScript — permite limpar o campo sem gerar NaN no estado.
- Ao mover rota para fora de `LayoutApp`, a rota precisa estar dentro de `RotaProtegida` mas fora do `<Route element={<LayoutApp />}>` — a ordem importa pois o React Router v7 usa correspondência por posição.
