## Decisões Tomadas

- **TASK-RF-6.3 dividida em execução:** planejamento original cobria Perfil + Ajustes. Dividida em duas tasks para manter escopo coeso. PaginaAjustes → TASK-RF-6.3.1.
- **"Cria nova" → "Mudar veículo":** label mais claro para o usuário (objetivo, não ação técnica). Dialog explica que a predefinição atual é mantida.
- **`/perfil` fora de LayoutApp:** design não usa header da moto (marca/modelo/km/L); tem header próprio "Perfil". NavBar é renderizada diretamente em PaginaPerfil.
- **NavBar AJUSTES ativo em `/perfil`:** design Figma mostra AJUSTES ativo na tela Perfil. Implementado via `useLocation` no componente NavBar com check `tab.to === '/ajustes' && pathname === '/perfil'`.
- **Botões "Mudar predefinição" e exportar/importar desabilitados:** escopo de TASK-RF-7.1. Marcados com `disabled` sem tooltip para não poluir a UI agora.
