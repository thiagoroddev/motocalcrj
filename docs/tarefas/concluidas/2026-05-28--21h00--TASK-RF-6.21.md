## Decisões Tomadas

- **Layout B (pílulas na 3ª linha):** escolhido pelo humano como mais legível que linhas extras de texto puro.
- **Bloco de km como link único:** as duas pílulas (`km atual` + `última rev`) compartilham o mesmo destino (`/ajustes` seção Veículo), simplifica o toque e satisfaz min-h-touch de 48px com um único alvo.
- **Avatar e modelo navegam ambos para `/perfil`:** redundância proposital (UX comum); avatar é atalho rápido, modelo deixa explícita a ação de editar.
- **`location.state` ao invés de query param/hash:** segue padrão já estabelecido em `PaginaMaoDeObra`.
- **Inline links sem 48px estrito:** "N km/L" e "modelo" são inline em texto e não atingem 48px de altura visual; aceito como trade-off em troca de header compacto. Alvos com hover/underline para affordance. Pílulas (`min-h-touch`) absorvem o requisito de toque pleno para o caso mais relevante (km).
- **`flex-shrink-0` → `shrink-0` (canonical):** lint warning corrigido junto, mesma utilidade.
