## O problema que a tarefa resolve

Em dois dias o projeto ganhou: CI bloqueante, branch protection exigindo PR, portão de lançamento com
9 itens, registro de riscos aceitos com prazo, Dependabot com grupos, registro de configuração de
plataforma e uma regra nova de evidência (link do run).

**Nada disso estava documentado no repositório.** O manual de operação existia só no histórico de uma
conversa — que é precisamente a falha que a análise de 28/07 aponta em outros lugares: *conhecimento
que existe só na cabeça de quem fez não é processo.*

Sintoma concreto: com 3 PRs vermelhos do Dependabot abertos, o dono do projeto não sabia se eles
exigiam ação, se tinham prazo, ou como julgá-los.

Verificado antes de escrever: **nenhum documento cobria fluxo git, PR, ou como operar os gates.** O
`contexto-projeto-ai.md` lista os comandos (§10) mas não o "como trabalhar".

## Execução

Criado `docs/operacao.md` com sete seções, escritas para quem **não lembra de nada** e precisa
desbloquear em minutos:

| Seção | Responde |
|---|---|
| 1. Como fazer qualquer mudança | O ciclo branch → PR → merge, com comandos PowerShell copiáveis |
| 2. Quando algo dá errado | Tabela sintoma → causa → conserto, incluindo o "commitei em `motocustorj` por engano" |
| 3. Os PRs do Dependabot | **Como julgar sem ajuda**: é segurança ou versão? qual etapa falhou? |
| 4. Comandos e quando rodar | `verify`, `build`, `audit:prod`, `gate:lancamento` |
| 5. O que fica fora do repositório | Os 3 toggles de plataforma e o registro deles |
| 6. Glossário | 20 termos: CVE, GHSA, advisory, gate, chunk, vendor, peer dependency, LCP, CSP, precache… |
| 7. Se travar | As quatro garantias que evitam pânico |

### Decisões de conteúdo

- **Seção 3 é o coração da tarefa.** A pergunta do humano foi *"como eu julgo esses PRs sem IA? Se
  tiver X eu faço o quê?"*. A resposta virou heurística de duas perguntas — (1) é alerta de segurança
  ou versão nova? (2) qual etapa falhou? — com tabela de ação por etapa. Sem isso, o manual seria
  referência bonita que não desbloqueia.
- **"Na dúvida, feche com o motivo escrito."** Regra explícita, porque a paralisia vem de achar que
  fechar é perder algo. Fechar custa nada: o Dependabot reabre na próxima versão.
- **Seção 7 existe para reduzir medo, não para informar.** As quatro garantias ("nada no GitHub quebra
  a produção", "nenhum PR tem prazo", "trabalho local não se perde", "`git stash` em último caso") são
  o que permite mexer sem travar.
- **O aviso contra `grep` na saída de verificação** entrou na seção 4, citando a `TASK-BG-039` como
  caso real. É a lição mais transferível das duas últimas tarefas.
- **Glossário com 20 termos** porque a queixa foi literalmente "termos novos". Cada um definido em uma
  linha, no contexto deste projeto — não definição de dicionário.
- **Indexado no `contexto-projeto-ai.md` §12**, em primeiro lugar da tabela. Documento não indexado é
  documento que ninguém encontra — e o §12 é onde uma IA ou pessoa nova procura.

## O Que NÃO Foi Feito (e Por Quê)

- **Link no README.** O README é vitrine para quem avalia o projeto; manual de operação interna não
  é destaque para esse público. Fica no índice de documentos, que é onde se procura.
- **Tutorial de Git básico** (o que é commit, branch, merge). Fora de escopo: o manual assume Git
  conhecido e documenta o que é **específico deste repositório**.
- **Fechar os 3 PRs vermelhos.** É decisão do humano; o manual dá o critério para ele decidir sozinho,
  que era o pedido.

## Aprendizados Para o Projeto

- **Automação sem manual transfere o gargalo, não o resolve.** Os gates instalados nesta sessão
  funcionam, mas o dono do projeto ficou dependente de quem os montou para saber o que fazer com um PR
  vermelho. Ferramenta sem manual de operação é ferramenta de uma pessoa só.
- **A pergunta "se tiver X eu faço o quê?" é o teste de qualidade de um manual.** Um documento que
  descreve o sistema sem responder isso é referência, não manual.
- **Quem escreveu a automação é a pior pessoa para julgar se o manual está claro** — o contexto já está
  na cabeça. O sinal de que ele é necessário veio de fora, não de dentro.
