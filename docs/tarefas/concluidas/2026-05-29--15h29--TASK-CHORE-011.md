## Problema

O ambiente de dev roda com `NODE_ENV=production` (e `npm config omit=dev`). Qualquer `npm install <pkg>` podava as devDependencies do `node_modules` (vite, vitest, eslint, typescript, tailwind), quebrando build/lint/test até reinstalar com `--include=dev`. Observado na TASK-REF-25 ("removed 366 packages").

## Fix (opção A, escolhida pelo humano)

- Criado `.npmrc` versionado na raiz com `include=dev` (inverso de `omit=dev`; vence quando ambos presentes), com comentário explicando o porquê.

## Verificação

- `npm config get include` → `dev` (origem: "overridden by project"); `npm config get omit` → vazio, mesmo com `NODE_ENV=production`.
- `npm install` simples (sem flags, com o ambiente em produção) **manteve** vite, vitest, eslint, typescript, tailwind e react-minimal-pie-chart no `node_modules`.

## Decisões / Cuidados

- `include=dev` afeta apenas instalação local de dependências; não força `production=false` global, então não interfere em deploy/CI que dependam de `NODE_ENV`.
