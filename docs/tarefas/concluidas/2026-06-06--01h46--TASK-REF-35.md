## Decisões Tomadas

- **Preservar reexports no `PerfilContext.tsx`:** evita churn nos consumidores e mantém a API pública compatível.
- **Reducer em módulo próprio, sem subdividir o switch:** estabelece a fronteira de estado necessária sem uma reorganização comportamental arriscada.
- **Props estreitas em `DetalhesCategoriaSimples`:** o componente recebe apenas o custo anual da categoria, não o objeto completo de cálculos.
- **Formatadores específicos em módulo próprio:** funções puras ganharam testes diretos sem ampliar `formatters.ts` com regras exclusivas da tela.
- **Não tocar `calculos.ts`:** respeita o gatilho das revisões de origem e mantém o núcleo estável.

## Aprendizados Para o Projeto

- Extrações oportunistas funcionam melhor quando o arquivo tocado já possui testes de integração que preservam o comportamento externo.
- Reexports permitem reduzir arquivos centrais sem espalhar mudanças estruturais pelos consumidores.
- Em componentes de domínio, passar o dado mínimo usado pelo ramo extraído reduz acoplamento e simplifica os testes.
- No WSL 1 deste ambiente, gates de Node que falham no shell Linux podem ser validados pelo shell nativo do Windows sem mascarar o resultado.
