**🔴 Bloqueante:** nenhum.

**🟡 Importante**
1. Lógica nova de MVP sem teste: `normalizarPerfilMvp` (`useCustos`) e `normalizarAbaInicial` (`PaginaMaoDeObra`) não têm cobertura. `normalizarPerfilMvp` materializa a ADR-012 no cálculo - se removida, perfil legado em `independentes` volta a calcular no modo escondido silenciosamente, com testes verdes. **Encaminhado: TASK-REF-32.4 resolve os testes de normalização (decisão do humano 03/06/26).**
2. Escopo vs decisão de produto completa: a 32.2 entrega só o recorte de UI. "Não inferir mão de obra + aviso de custo incompleto no Detalhamento" é a TASK-REF-32.4 (pendente); `calculos.ts` não foi tocado. O filtro `servicosAvulsosAutorizada` já exige `precoTotalAutorizada > 0` (não-inferência parcial por estrutura), mas falta o aviso visível e os `SERVICOS_INDEPENDENTES_PADRAO` da Pop ainda têm defaults. Registrado para não dar falsa sensação de "pronto": fecha na 32.4.

**🟢 Sugestão**
- "Honda" interno permanece (`KM_CICLO_REVISAO_HONDA`, `basePacoteHonda`, `quantidadeRevisoesCicloHonda`, comentários); não é UI - renomear quando a 32.4 abrir `calculos.ts`.
- `SecaoPreferencias.temAlteracao` ainda compara `modoRevisao !== 'autorizadas'`, vestigial sem UI para alterar o modo; inofensivo.
- `modoRevisaoLabel = 'Concessionária'` constante em `PaginaDetalhamento`; ok como rótulo nomeado.
