## Decisões Tomadas

- **`Accordion type="multiple"`:** Permite abrir vários items simultaneamente — o usuário pode editar óleo e kit relação ao mesmo tempo sem fechar o primeiro.
- **km=0 exibido como vazio no Input:** `value={moto.kmUltimaTrocas[key] || ''}` — o 0 é o "não registrado", não faz sentido exibi-lo numericamente. Placeholder "Ex: 12000" orienta o usuário. Ao limpar o campo, `km` volta para 0.
- **"Fazer Motor" condicional com `kmAtual >= 60_000`:** Irrelevante para motos com menos km; aparecer antes confunde mais do que ajuda.
- **Posição entre Veículo e Preferências:** Proximidade lógica com os campos de km (kmAtual, kmUltimaRevisao) que estão na seção Veículo acima.
- **Trigger mostra resumo inline:** `label + km resumido (ou "não registrado")` — evita que o usuário precise abrir cada accordion para saber o que já registrou.

## O Que NÃO Foi Feito (e Por Quê)

- **Campo de data da troca:** Escopo limitado a km; datas seriam relevantes apenas se o calculador usasse tempo além de distância. Não entra nesta tarefa.
- **Estilo customizado no AccordionTrigger:** O `hover:underline` padrão do shadcn é aceitável aqui; não vale sobrescrever agora.

## Aprendizados Para o Projeto

- `Accordion type="multiple"` é a escolha correta quando os items são independentes entre si — o usuário pode precisar editar mais de um sem fechar o anterior.
- `value={campo || ''}` para campos numéricos com default 0 é o padrão correto quando 0 significa "não informado" — o usuário vê um campo vazio com placeholder em vez de um zero confuso.
