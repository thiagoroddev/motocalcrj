## Decisões Tomadas

- **Incompleto Honda = `concessionariaIncluiPeca: false`** (não ausente/undefined). Casos: sapata dianteira do Start (R$ 19,50) e sapata traseira de Fan/Titan (R$ 40,00).
- **`precoParalela = precoOriginal`** (extras/pneu/bateria: a fase 1 curou média de mercado única; oculto no MVP). **óleo/vela/filtro/kit_revisao = baseline Honda do Pop** onde a fase 1 só tinha o oficial completo (são `incluidoNaRevisaoAutorizada` → pulados no fluxo Honda autorizada; impacto ~nulo).

## Aprendizados Para o Projeto

- **"Completo" tem duas funções que divergem em `undefined`:** `concessionariaInformaPrecoCompleto` (`=== true`) × `ehPecaCobertaPorServicoCompleto` (`!== false`). Modelar avulso "só M.O." como `concessionariaIncluiPeca: false` (explícito) faz as duas concordarem — não deixar a flag ausente.
- **O updater de FIPE exige `_fonte` com `dataColeta` + `codigoFipeNota` + `anoModelo {inicio,fim}`** em **todo** preset; um preset sem esses campos **quebra o script para o repo inteiro** (itera todos e aborta no primeiro fora do padrão).
- **Modelos com código FIPE fragmentado** (Titan 2026; Bros 2025+) não são cobertos pelo `fipe:update` atual (um código por preset) → usar valores manuais e não rodar o update até o script consolidar múltiplos códigos.
- **Criar um preset auto-registra o modelo** no onboarding (CATALOGO derivado de `LISTA_PRESETS`).
