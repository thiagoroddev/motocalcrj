## Decisões Tomadas

- **`CabecalhoVoltar` usa shadcn `Button variant="ghost" size="icon"`:** o botão voltar é um botão de ícone — `size="icon"` é o mapeamento semântico correto. `className` sobrescreve a cor e remove o `hover:bg-accent` padrão do ghost, mantendo o visual original (`hover:text-foreground hover:bg-transparent`).
- **`useNavigate` interno em `CabecalhoVoltar`:** o comportamento é sempre `navigate(-1)`, sem variação esperada. API simples: só `titulo` como prop. Testabilidade é menor, mas o componente vive em contexto de rota de qualquer forma.
- **`IconVoltar` adicionado ao sistema de ícones:** o ícone anterior era um SVG stroke-based inline (estilo diferente dos demais). O novo usa Material Design filled, consistente com o resto do sistema centralizado (TASK-CHORE-009).
- **Prettier expandiu o ternário de `porKmSemAlimentacao`:** o ternário multiline que escrevi foi colapsado para uma linha pelo auto-fix. Resultado correto, sem impacto funcional.
