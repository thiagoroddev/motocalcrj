## Decisões Tomadas

- **Split em 3 (não 2) módulos:** a alternativa de mover só `migrarPerfil` e reimportar os defaults do `PerfilContext` criaria import circular (funcionaria por uso tardio, mas é smell). Extrair os defaults para um módulo-folha elimina o ciclo na raiz.
- **Re-export de `perfilPadrao`/`SERVICOS_INDEPENDENTES_PADRAO`/`PRESETS_GASTOS_PADRAO` do `PerfilContext`:** ~6 arquivos (componentes/páginas/testes) importam esses símbolos de `PerfilContext`; re-exportar mantém a API pública estável e zera o churn nesses arquivos. Refatoração pura de verdade.
- **`migrarPerfil` tem novo lar canônico (`migracoes`):** o teste passou a importá-lo de lá (1 linha), em vez de re-exportá-lo do `PerfilContext` - evita dois lares públicos para a mesma função.
- **Extração via script content-anchored:** mover ~375 linhas à mão é propenso a erro; o script ancorou por conteúdo (não por número de linha, que havia mudado), extraiu verbatim e removeu os blocos. Validação por `tsc`/testes/`build`.

## O Que NÃO Foi Feito (e Por Quê)

- **Não reorganizei a migração em tabela por versão** (`{ 6: ..., 7: ... }`), que o "fix proposto" sugeria como opcional. Mantive a cadeia de `if` sequencial **idêntica** para garantir comportamento bit a bit. A tabela pode virar refatoração separada se desejado - agora é barata, isolada em `migracoes.ts`.
- **Não movi os testes de migração para um `migracoes.test.ts` próprio:** eles vivem em `PerfilContext.test.ts` interligados aos testes de reducer; movê-los seria churn alto sem ganho real. Continuam verdes importando `migrarPerfil` de `migracoes`.

## Aprendizados Para o Projeto

- **Extrair função de um arquivo-Deus exige mapear as dependências de dados primeiro.** `migrarPerfil` parecia isolada, mas dependia de 5 defaults internos - mover só ela criaria ciclo. A solução limpa quase sempre é um terceiro módulo-folha com o que ambos compartilham.
- **Re-export é a ferramenta certa para refatoração de estrutura sem quebrar API.** Mover a definição e re-exportar do lar antigo mantém o diff cirúrgico e os consumidores intactos.
- **Para mover centenas de linhas, prefira extração mecânica (script content-anchored) à transcrição manual** - menos erro, e `tsc`/testes/`build` validam o resultado.
