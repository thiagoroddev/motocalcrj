## Notas para o App

- `mao_de_obra: 0` representa mão de obra **Gratuita** (revisões 1.000 km e 6.000 km)
- Os valores de peças e mão de obra devem ser **editáveis** pelo usuário, pois variam por região e concessionária
- O ciclo completo de revisões cobre **36.000 km / 3,5 anos**
- Custo total acumulado das 7 revisões (Honda): **R$ 2.534,24**
- As revisões de maior custo são: 12.000 km (R$ 548,15), 36.000 km (R$ 642,60) e 24.000 km (R$ 638,15)
- Serviços avulsos com preço "a combinar" devem abrir campo de input manual no app
- Serviços com preço mínimo devem exibir o valor como referência, mas também permitir edição
- **Recall** não tem custo - pode ser tratado como `preco: 0, tipo: "recall"` no schema
- Oficinas independentes cobram **peças separado** - o app deve permitir registrar MO e peças em campos distintos
- Identificar cada fonte como `"oficina_rj_1"`, `"oficina_rj_2"` etc. para rastrear origem dos preços

### Sobre o Ciclo Após 36.000 km

O ciclo Honda simplesmente reinicia. A lógica é:

```
km_no_ciclo = km_atual % 36000
```

Exemplo: moto com 50.000 km está no equivalente à revisão de 14.000 km (50.000 % 36.000 = 14.000), ou seja, próxima revisão é a de 18.000 km do ciclo.

### Sobre Motos com Histórico Desconhecido

Para entregadores que compraram moto usada sem saber o km da última revisão, sugerimos três modos no app:

**Modo A - Ponto zero:** o app ignora o histórico e começa a contar do km atual. O usuário acompanha daqui pra frente. Mais simples.

**Modo B - Última revisão conhecida:** o usuário informa o km da última revisão que sabe que foi feita. O app calcula as próximas a partir daí.

**Modo C - Checklist de entrada:** o usuário marca quais itens já foram verificados/trocados recentemente na moto. O app ajusta os próximos alertas com base nisso. Mais preciso para moto usada.

> 💡 Para o app: o Modo A é o padrão para novos cadastros. Modos B e C ficam disponíveis nas configurações avançadas.
