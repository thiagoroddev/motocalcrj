**DT-14 - Uso de `SET_ONBOARDING_CAMPO` fora do Onboarding** 🔴 *Prioridade alta*

**Situação atual:**
A action `SET_ONBOARDING_CAMPO` aceita `campo: string, valor: unknown` e é usada fora do contexto do Onboarding (em telas de Ajustes, Mão de Obra, Autonomia) para alterar campos sem actions dedicadas. Exemplos: `financeiro.situacaoMoto`, `financeiro.responsabilidadeAluguel`, `perfilManutencao.*`.

**Por que é dívida técnica:**
- **Type-safety perdida:** `unknown` aceita qualquer valor incompatível - TypeScript não consegue garantir que `valor` é compatível com `campo`.
- **Invariantes não protegidas:** action pode sobrescrever blocos inteiros, violando INV-FIN-1, INV-MANUT-*, etc.
- **Confusão semântica:** action nomeada "ONBOARDING" sendo usada fora do Onboarding contraria INV-CONV-1 (Linguagem Ubíqua).

**Por que NÃO refatorar imediatamente:**
Funciona em produção, sem bug observado, refatoração exige mapear todos os usos antes.

**Gatilho que justifica endereçar:**
**Endereçar antes de TASK-5.1 (formulários de Registros)** - porque registros vão chamar muitas actions de update, e é o momento certo para introduzir actions específicas em vez de reaproveitar a do Onboarding.

**Recomendação:**
Criar actions específicas progressivamente. Lista inicial:
- `SET_SITUACAO_MOTO`
- `SET_RESPONSABILIDADE_ALUGUEL`
- `SET_PERFIL_PECAS_GLOBAL`
