# ADR-002: Alinhamento do token de border-radius ao padrão shadcn/ui

- **Status:** Aceita
- **Data:** 17/05/26
- **Contexto:** TASK-REF-05
- **Decisores:** Humano + IA

---

## Contexto

O projeto definiu `--radius-card: 8px` como token de border-radius para cards no bloco `@theme inline` do Tailwind v4. O shadcn/ui usa `rounded-lg` (0.5rem = 8px no Tailwind v4 padrão) como classe padrão no componente `Card`. Embora os valores em pixels sejam idênticos, os **tokens são diferentes**, o que forçava um override `className="rounded-card"` em cada uso de `<Card>`.

Exemplo do problema em `CardPeriodo.tsx` antes desta ADR:
```tsx
<Card className="rounded-card shadow-none border-0 p-md ...">
```

O `rounded-card` era redundante (mesmo valor que `rounded-lg`) mas necessário para sobrescrever `rounded-lg` com o token semântico do projeto.

---

## Decisão

**Opção 1 — Adotar a convenção shadcn (escolhida):**

1. Definir `--radius: 0.5rem` no `:root` como CSS var de design (padrão shadcn)
2. Mapear `--radius-lg: var(--radius)` no `@theme inline`, tornando `rounded-lg` dependente do design token
3. Remover `--radius-card: 8px` do `@theme inline`
4. Substituir todas as ocorrências de `rounded-card` → `rounded-lg` na codebase (17 arquivos)

---

## Alternativa Descartada

**Opção 2 — Modificar `card.tsx` para usar `rounded-card`:**

Manter o token do projeto como source of truth e alterar `card.tsx` para `rounded-card` em vez de `rounded-lg`. Descartada porque:
- Cria divergência permanente entre o `card.tsx` gerado pelo shadcn CLI e o do projeto (regenerações futuras via `npx shadcn add` sobrescreveriam a mudança)
- Mantém nomenclatura própria (`rounded-card`) que diverge da convenção shadcn, dificultando a leitura de devs familiarizados com shadcn

---

## Consequências

- `--radius` vira o token primário de card radius; pode ser alterado em `:root` para mudar todo o sistema de uma vez (future-friendly)
- `rounded-lg` passa a ser semanticamente equivalente a "card radius" no projeto
- 17 arquivos `.tsx` com `rounded-card` → `rounded-lg` (bulk replace, sem impacto visual)
- `CardPeriodo.tsx` perde o override `rounded-lg` redundante no className
- 3 containers `<div bg-card>` em `components/detalhamento/` migram para shadcn `<Card>`
- `rounded-btn: 4px` e `--radius-input: 4px` **não são afetados** — seguem como tokens semânticos separados
